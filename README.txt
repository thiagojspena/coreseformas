CORES & FORMAS — PWA SIMPLES

Arquivos que devem ficar juntos:
index.html
manifest.webmanifest
sw.js
icon.png

Não existe pasta icons nesta versão.

Publique os quatro arquivos no mesmo nível em um site HTTPS, como GitHub Pages.
No Chrome Android, abra o site e use o botão "📲 Instalar" quando ele aparecer.
Se o botão não aparecer, o navegador pode estar ocultando a instalação até que os critérios
do PWA sejam atendidos (HTTPS e Service Worker ativo, entre outros).
No iPhone/iPad, a instalação é feita pelo menu Compartilhar > Adicionar à Tela de Início.
